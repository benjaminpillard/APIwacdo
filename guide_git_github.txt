GUIDE RAPIDE - CREER UN DEPOT GIT + GITHUB (Windows)

0) Ouvrir le terminal dans le dossier du projet
cd C:/Users/Benjamin/desktop/APIwacdo

1) Verifier que Git est installe
git --version

2) Configurer ton identite Git (une fois)
Option projet courant:
  git config user.name "Ton Nom"
  git config user.email "ton.email@example.com"

Option globale (tous tes projets):
  git config --global user.name "Ton Nom"
  git config --global user.email "ton.email@example.com"

3) Initialiser Git dans le projet (si besoin)
git init

4) Ajouter un .gitignore Python (important)
Exemple contenu .gitignore:
  .venv/
  __pycache__/
  *.pyc
  app.db
  .env

5) Faire le premier commit
git add .
git commit -m "Initial commit"

6) Mettre la branche principale en main
git branch -M main

7) Creer le depot sur GitHub
- Aller sur: https://github.com/new
- Nom du repo: APIwacdo (ou ton nom)
- Public ou Private
- IMPORTANT: ne pas cocher README/.gitignore/license si ton projet local existe deja

8) Connecter le remote GitHub
Remplacer TON_USER et TON_REPO:
  git remote add origin https://github.com/TON_USER/TON_REPO.git

Si origin existe deja:
  git remote set-url origin https://github.com/TON_USER/TON_REPO.git

9) Envoyer le code sur GitHub
git push -u origin main

10) Workflow quotidien (recommande)
git status
git add .
git commit -m "message clair"
git push

11) Commandes de verification utiles
git remote -v
git branch -a
git log --oneline -n 10

12) Erreurs frequentes et correction rapide
- "src refspec main does not match any"
  -> Aucun commit sur main. Faire d abord:
     git add .
     git commit -m "Initial commit"

- "Repository not found"
  -> URL remote fausse ou repo non cree sur GitHub.
     Verifier:
     git remote -v

- "rejected (fetch first)"
  -> Le remote contient deja des commits.
     Faire:
     git pull --rebase origin main
     git push

13) Reconnecter un projet local a un nouveau repo GitHub plus tard
git remote remove origin
git remote add origin https://github.com/TON_USER/TON_REPO.git
git push -u origin main
